# Seller request search and review controls

The marketplace operations queue can find watch registration requests by seller name or case code. A request review shows seller changes to listing details, including price and photos. Operators can correct request text and replace photos before repair approval. After initial approval, staff can still request a correction or reject a watch before publication, subject to the repair decision state.

Focused isolated checks passed for search, operator photo replacement, authorization boundaries and the prepublication decisions. The updated admin pages were rendered with sample data and inspected at phone and desktop widths without horizontal overflow. The scoped production files passed hash and PHP syntax checks, and the installed plugin reports version 0.159.48. No real seller request or listing was changed during validation; authenticated operator use remains to be observed in normal operations.
