# Connecting seller rules to purchase policies

Customers should be able to move from seller rules to the applicable purchase, shipping and return terms without searching through another page. The installed marketplace update adds a direct link to that section of the shared store policy, with a reciprocal route back to seller terms.

Commercial figures that already come from settings remain in their existing renderer. Information-use copy is bounded to what the workflow supports instead of making universal technical promises. Rules navigation uses shared storefront colors, visible keyboard focus and usable touch targets.

The companion flow suite passes 335 checks. Eight combined store/marketplace browser previews cover mobile/desktop in light/dark themes, including anchor navigation, focus, hover and overflow. Screenshots were inspected; no real order, message or financial record was created for presentation testing.

This update is installed with owner approval, scoped backups and post-install source checks. A further 500 read-only checks cover the installed page configurations and actual navigation between both policies. Offline/PWA behavior is outside this validation. Business-specific legal review and earlier real-world payment/handoff acceptance remain separate work.
